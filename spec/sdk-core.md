# sdk-core：公共会话与包基础

## 目标

业务应用只配置宿主会话接口和一个协议适配器，即可使用同一套登录状态、页面跳转与本域登出 API。核心不依赖 Vue、React 或某种认证协议，也不在浏览器中处理身份令牌、SAML 断言、CAS 票据或 Kerberos 凭据。

## 范围与边界

- 本模块拥有 `createSSO`、公共状态与类型、宿主会话响应映射、导航约束、自动登录防循环和 npm 包的根入口。
- 协议模块只实现 `ProtocolAdapter.loginUrl({ returnTo })` 等协议差异，并各自验证认证中心与宿主后端交互。
- 宿主后端负责认证结果校验、业务 API 鉴权、创建与失效本域会话；SDK 以宿主会话接口的结果为准，不用前端状态代替后端鉴权。
- Vue、React 和 Vite 的接线与兼容结论属于 `host-compatibility`；本模块只保证框架无关及导入时不访问浏览器全局变量。

## 公共契约

1. `createSSO(config)` 返回 `getState`、`getSession`、`ensureAuthenticated`、`login`、`logout`、`onAuthChange`。配置允许注入 `fetch`、导航、当前 URL 和临时存储，业务项目不必修改全局对象。
2. 状态为 `unknown`、`checking`、`authenticated`、`unauthenticated` 或 `error`。已登录状态携带由宿主响应映射得到的用户数据；订阅者能观察状态变化并取消订阅。
3. 会话查询默认向宿主接口发送同源凭据并禁用缓存。`401` 或有效响应中的 `authenticated:false` 表示未登录；网络错误、非预期 HTTP 状态和无效响应进入 `error`，不得伪装成未登录。宿主可配置响应映射，但映射结果仍必须满足公共会话契约。
4. `login` 与 `ensureAuthenticated` 只接受同源回跳目标，并将规范化后的路径、查询和片段传给协议适配器。登录地址的协议特定参数和合法性由适配器负责。
5. `ensureAuthenticated` 在未登录时最多触发一次自动导航；回到应用仍未建立会话时报告循环错误。用户主动 `login` 可重置并记录一次新的登录尝试，取消或失败返回后不得再次自动跳转；用户仍可再次主动重试。并发的受保护页面检查只触发一次会话查询和导航。
6. `logout` 调用宿主后端的 POST 接口，允许业务提供必要请求头；只在后端确认成功后将本域状态置为未登录。重定向或失败响应不得被视为登出成功。全局单点登出不属于此 API 的默认语义。
7. 过时的会话查询结果不得覆盖较新的登出状态。模块可在 Node/SSR 环境导入，浏览器全局变量仅在调用需要浏览器能力的方法时读取。

## 包与测试约束

- 使用一个无框架运行时依赖的 ESM npm 包，保留根入口与按需导入的协议子路径；示例宿主、测试服务和互操作测试均为私有工作区，不进入发布包。
- 单元测试覆盖公共状态、会话响应映射、错误区分、同源回跳、防循环、并发检查、登出失败和旧请求覆盖风险。
- 通过类型构建、Node 环境根入口导入与打包内容检查。协议提供方的真实互操作和浏览器兼容测试分别在后续模块验收。

## 验收标准

- 业务项目通过宿主会话接口和任一符合契约的适配器完成公共登录闭环，无需引用框架运行时或协议令牌库。
- 上述成功与失败状态有可复现的自动化测试；测试失败时不降低错误语义或放松同源回跳约束。
- 包的公开类型与入口可导入，构建产物不包含私有测试工作区。
