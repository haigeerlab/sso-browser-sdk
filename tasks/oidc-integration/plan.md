# oidc-integration 实施计划

依据：[OIDC 模块 Spec](../../spec/oidc-integration.md)。继续使用现有无框架 SDK 核心和宿主后端会话模式；认证中心及宿主后端均为测试工作区，SDK 发布包不包含它们。

1. **已有能力核对**：核对 `/oidc` 配置边界、简版夹具、真实 `oidc-provider` 互操作和浏览器证据。验证：逐项标出已证明与尚未证明的场景，不把简版夹具当真实协议实现。
2. **异常路径补测**：在真实参考实现中验证中心会话过期后 App B 重新要求登录、用户取消或认证中心返回错误后宿主不建立会话且业务页面进入可见错误状态。先写能复现缺口的测试，再做最小后端测试服务或示例页面修复；不把协议校验移入前端 SDK。
3. **文档与回归**：更新 SDK README 中过时的“真实 OIDC 尚未验证”表述，记录参考提供方版本、开发配置及剩余边界。运行 SDK 单元、双宿主简版交互、真实互操作和 Vue/React 构建；必要时做浏览器复测。
4. **模块验收**：核对 Spec 评审结果、异常路径证据及本域登出边界，再完成 todo。生产认证中心、真实业务宿主与全局单点登出作为 `release-readiness` 的独立验收，不从本机参考实现推断通过。

每一步的测试结果写入 `tasks/oidc-integration/verification.md`；发现协议行为与预期不符时先记录并定位，再调整实现或 Spec。
