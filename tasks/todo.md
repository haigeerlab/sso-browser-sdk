## 1. 公共契约

**依赖：** 无。**范围：** 文档与类型草案。

- [x] 定义会话状态、用户数据最小字段和一致的错误语义。
- [x] 定义协议适配器接口和宿主会话 API 契约；明确哪些字段可配置。
- [x] 用 OIDC、CAS、SAML 三个接入例子检查接口不会强迫宿主暴露无关字段。

**验证：** 文档中的三种配置能表达真实流程；未登录与网络错误可区分。

**验证：** 包构建与基础测试通过；Node 环境可导入根入口。

## 3. 公共会话闭环

**依赖：** 1–2。**范围：** 核心状态、导航、测试。

- [x] 未登录、网络失败、回跳地址非法和重复自动跳转有可预测结果。

## 4. OIDC 后端会话模式

**依赖：** 3。**范围：** OIDC 适配器与简版服务夹具。

- [x] 未登录时导航到宿主 OIDC 登录入口，返回后恢复目标页面（简版浏览器夹具）。
- [x] 中心 Cookie 缺失时重新显示登录页；错误回调不建立本域会话。
- [ ] 中心会话实际过期及错误回调后的 SDK 提示完成浏览器验证。
- [x] OIDC 安全校验责任列入宿主后端验收清单。

**验证：** 夹具端到端场景与异常场景通过；协议互操作留待任务 7。

## 5. CAS 票据模式

**依赖：** 3。**范围：** CAS 适配器与夹具。

- [x] 宿主后端回调模式可完成双宿主登录与页面恢复，Vue/React 浏览器实测通过。
- [x] 首阶段采用宿主后端回调，SDK 不直接接收或验证 Service Ticket。
- [x] 服务不匹配、票据过期或重复验证时后端拒绝建立本域会话。

**验证：** 夹具端到端及失败场景通过；协议互操作留待任务 7。

## 6. SAML 后端回调模式

**依赖：** 3。**范围：** SAML 适配器与夹具。

- [x] SDK 启动 SP 登录入口并在 ACS 完成后恢复会话，Vue/React 浏览器实测通过。
- [x] SDK 不读取或验证 SAML Response；宿主后端签名与断言校验责任写入验收清单。
- [x] 简版夹具的非法 RelayState、过期响应与重放回调被拒绝；成功后恢复原页面。

**验证：** 夹具端到端及失败场景通过；协议互操作留待任务 7。
