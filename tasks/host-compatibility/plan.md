# host-compatibility 实施计划

依据：[宿主兼容性 Spec](../../spec/host-compatibility.md)。本模块验证实际 npm 包在 Vue 3.4.0、React 19.3.0、Vite 5.0.0 中的接入，不新增协议逻辑或 Webpack 配置。

## 切片 1：现状与基线

- 核对 SDK 包导出、示例宿主的依赖解析及现有浏览器证据。确认当前构建引用工作区软链接，尚未证明独立安装。
- 运行现有 SDK 单元测试、Vite 构建，记录 Node/npm/框架版本与缺口。

## 切片 2：打包产物的独立消费

- 先写验证脚本，创建系统临时目录，`npm pack` SDK 后让隔离 Vue/React 宿主从 tarball 安装；确认不会通过 workspace 链接回源码。
- 对两个消费者验证根入口与 OIDC/CAS/SAML 子路径导入、类型检查、Vite 5 开发服务器与生产构建。将可复测脚本接入根目录回归，不持久化 tarball 或临时安装目录。

## 切片 3：宿主差异的配置接入

- 在简版后端增加一个非默认会话响应和一个非默认回跳参数名；两个示例通过 `session.map`、`returnToParam` 消费，而不修改 SDK 核心。
- 对这两种差异先做自动化测试，再在浏览器确认登录、刷新恢复、登出、错误反馈及手动重试。

## 切片 4：矩阵与收尾

- 在实际浏览器验证代表协议的双宿主流程；核对控制台错误、开发服务与构建资源、SDK 包内容和运行时依赖。
- 运行 `npm test`、Spec Guard 产物检查，更新接入文档、兼容矩阵和 `verification.md`。仅对实测组合给出结论。

## 风险与停止条件

- `npm pack`/安装若无法在隔离目录解析依赖，应保留错误并修复包或安装脚本，不用工作区软链接代替。
- 参考服务的协议互操作已在前序模块验证；本模块只重测必要的浏览器代表路径。生产宿主和其他浏览器版本归发布准备进一步确认。
