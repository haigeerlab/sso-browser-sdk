# developer-docs 实施计划

依据：[Spec](../../spec/developer-docs.md) 与 [ADR-001](../../docs/decisions/001-developer-documentation.md)。设计及本轮实施已于 2026-10-07 获用户“继续”确认。

## 环境与工具

Node 22.22.0、npm、现有 Python CAS 环境、JDK/OpenSSL、内置浏览器工具可用。用户明确选定 VitePress 2.0.0-alpha.20；文档示例通过实际 tarball 的隔离消费者验证。监听测试服务或访问 npm 时使用获准的本机执行。浏览器用于站点导航/搜索/移动布局及示例接入自验。

## 切片 1：站点骨架（report）

建立私有文档工作区、VitePress 默认主题、内容导航与搜索，增加根目录命令和生成物忽略规则。锁定框架和检查既有兼容宿主的 Vue/Vite 解析。

验证：`npm run docs:build`，安装依赖版本核对；保留死链失败行为。

## 切片 2：指南、API 与 README（report）

按设计大纲写页面，复核 SDK 源码和参考后端路由；明确当前 tarball 安装、状态语义、回调错误、五协议责任与支持边界。同步两份 README 与旧接入指南的入口。

验证：站点构建；Markdown 链接/锚点检查；包清单。

## 切片 3：可执行示例（report）

共享客户端初始化和错误展示，交付完整原生 TS、Vue、React 示例；协议页面复用实际配置文件。新增隔离安装验证命令，从新 tarball 安装并类型检查/构建示例，验证接口和协议配置。

验证：`npm run docs:check`。检查只围绕可复制示例和文档链接，不增加镜像实现的测试。

## 切片 4：开发者验收与修订（report）

从 README 开始按文档读取并操作，运行文档示例连接现有独立参考后端；浏览器自验站点、搜索、移动阅读和前端认证流程。审查公共 API/协议入口/HTTP 契约/示例与证据，记录稳定发现及缺口。

验证：根路径与子路径文档构建、`npm test`、SDK 生产依赖及文档开发依赖审计、`npm pack --dry-run`、Spec Guard；结果写入 `verification.md`。

## 最终审阅（gate）

AI 验证与修订完成后，将本地站点及开发者验收报告交给用户审阅。此项只在用户完成审阅后勾选；不把浏览器自验当成人工确认。企业域、实际业务后端与远端部署仍不在本次完成声明中。

首步是站点工作区与框架安装；普通切片通过即继续，不重复请求设计授权。遇到版本不可用、权限被拒、超出设计的源码行为变更时记录具体问题并停止相关步骤。
